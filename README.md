# Excel 多列匹配与标黄工具

一个基于 Python 标准库的 Excel 数据核对脚本。按自定义字段组合对比两个 `.xlsx` 工作簿，汇总源文件中指定工作表的数据，并在目标文件的副本中将匹配单元格标为黄色。

适用于设备点表、参数表、端口与寄存器地址等结构化数据的交叉核对。

## 功能

- **多列联合匹配**：只有同一行的所有配置字段都匹配，才判定为命中。
- **多个源工作表**：从同一个源工作簿的多个指定工作表读取数据，匹配目标工作簿中的一个工作表。
- **灵活指定列**：支持表头名称、Excel 列字母，以及自定义需要标黄的列。
- **可选比较规则**：支持编码、数字、文本和原始文本比较。
- **三种操作方式**：交互式填写、JSON 配置、命令行参数覆盖。
- **只读预检查**：检查配置、匹配情况和样式修改，不生成 Excel 文件。
- **输出独立副本**：只修改匹配单元格的填充样式，保留原输入文件；输出文件已存在时停止。
- **无需第三方包**：使用 `zipfile`、`xml.etree.ElementTree` 等 Python 标准库处理 OOXML。

## 运行环境

- 建议使用 Python 3.10 或更高版本。
- 输入文件必须是普通、未加密的 `.xlsx` 工作簿。
- 无需安装 `pandas`、`openpyxl` 或 Microsoft Excel。

下文以 Windows PowerShell 为例。在脚本所在目录打开终端后运行命令。

## 快速开始

### 方式一：交互式填写

```powershell
python ".\多excal文件相同项对比脚本.py"
```

按提示依次填写目标文件和工作表、源文件和工作表、比较字段、比较规则、标黄列及输出路径。

目标文件是需要被标黄的文件，源文件是提供参考数据的文件。输入文件或列名时可以使用中文。

提示中的方括号表示默认值，直接回车即可采用。脚本内置的 `source.xlsx`、`target.xlsx`、`来源表A` 和 `来源表B` 均为虚构示例，使用前请改成自己的文件和工作表。位于脚本目录下的路径在提示中以相对路径显示，避免展示其上级目录。交互模式默认只做检查，需要生成结果时按提示输入 `y`。

### 方式二：使用 JSON 配置

首次使用时，将示例复制为自己的配置；已有 `match_config.json` 时直接编辑现有文件：

```powershell
Copy-Item .\match_config.example.json .\match_config.json
```

修改配置中的文件路径、工作表名和列名，再进行预检查：

```powershell
python ".\多excal文件相同项对比脚本.py" --config .\match_config.json --dry-run
```

确认匹配情况后生成标黄副本：

```powershell
python ".\多excal文件相同项对比脚本.py" --config .\match_config.json --write
```

`--dry-run` 与 `--write` 互斥；未指定时，使用配置中的 `options.dry_run`。示例配置默认为只检查。

### 方式三：命令行覆盖

命令行参数可以覆盖 JSON 中的对应设置，例如临时更换输出文件名：

```powershell
python ".\多excal文件相同项对比脚本.py" --config .\match_config.json --output .\result_02.xlsx --write
```

查看所有参数：

```powershell
python ".\多excal文件相同项对比脚本.py" --help
```

也可以使用配置作为交互模式的默认值：

```powershell
python ".\多excal文件相同项对比脚本.py" --interactive --config .\match_config.json
```

显式使用 `--interactive` 时，文件、工作表和字段信息应在提示中填写，不要同时传入这些项目的命令行覆盖参数。

## 配置说明

完整示例见 [match_config.example.json](match_config.example.json)。

| 配置项 | 说明 |
| --- | --- |
| `target.file` | 需要被标黄的目标工作簿路径 |
| `target.sheet` | 目标工作表名称，只处理这一张工作表 |
| `target.header_row` | 表头行号，从 1 开始；`null` 表示自动识别 |
| `target.key_columns` | 目标侧比较字段，按顺序填写表头名称或列字母 |
| `target.mark_columns` | 匹配后需要标黄的列；省略时使用目标比较字段 |
| `source.file` | 提供参考数据的源工作簿路径 |
| `source.sheets` | 参与比较的源工作表名称列表 |
| `source.header_row` | 源工作表表头行号，从 1 开始；`null` 表示自动识别 |
| `source.key_columns` | 源侧比较字段，顺序与目标侧一一对应 |
| `normalizers` | 各组字段的比较规则；省略时全部使用 `text` |
| `output` | 标黄副本的输出路径，应使用新的 `.xlsx` 文件名 |
| `options.dry_run` | `true` 只检查；`false` 生成文件 |
| `options.require_all_source_keys_to_match` | `true` 时，任一完整源键在目标侧找不到都会停止生成；默认 `false` |
| `options.max_unmatched_keys` | 最多打印多少个未匹配源键，默认 20；设为 0 不打印明细 |

JSON 中的相对路径均以**配置文件所在目录**为基准；命令行覆盖的文件路径以**当前终端目录**为基准。源文件、目标文件和输出文件必须是不同路径。

### 匹配示例

下列字段按列表中的位置逐项对应：

| 目标字段 | 源字段 | 比较规则 |
| --- | --- | --- |
| 参数Code | 点位编码 | `code` |
| 监听端口 | 点位对应端口号 | `number` |
| 寄存器地址 | 点位寄存器地址 | `number` |

例如，目标行 `DEV_001 / 1502 / 100` 可以匹配源行 `dev_001 / 1502.0 / 0100`。如果寄存器地址变为 `101`，即使前两个字段相同，也不会命中。

匹配时，目标行的字段组合必须完整出现在**某一条源数据行**中，不能分别从不同源行拼接匹配。

### 比较规则

| 规则 | 行为 | 示例 |
| --- | --- | --- |
| `code` | 全角兼容规范化，删除空白，忽略大小写 | `ab 01` 与 `AB01` 相同 |
| `number` | 规范化数字表示，忽略空白及无意义的前导零、小数末尾零 | `001`、`1` 与 `1.0` 相同 |
| `text` | 全角兼容规范化，去除首尾空白，保留大小写及中间空格 | ` ABC ` 与 `ABC` 相同，`abc` 与 `ABC` 不同 |
| `raw` | 比较读取到的原始单元格文本，不额外规范化 | 保留大小写、空白等差异 |

编码中的前导零有意义时，请使用 `code`、`text` 或 `raw`，避免使用 `number`。`raw` 比较的是文件中读取到的文本，不是 Excel 按单元格格式渲染出的显示字符串。

### 列与表头

列可以写成 `"参数Code"` 等表头名称，也可以写成 `"A"`、`"C"` 等列字母。普通短字母会先尝试匹配表头，再回退为列字母；可用 `"header:ID"` 强制指定表头，用 `"column:ID"` 强制指定列字母。

表头名称匹配时忽略大小写和空白。`header_row` 为 `null` 时，使用表头名称的配置会在前 10 行中查找；纯列字母配置会将工作表的第一个实际行视为表头。

## 处理范围与限制

- 一次处理两个工作簿：一个源文件和一个目标文件。源侧支持多个工作表，目标侧处理一个工作表。
- 只支持 `.xlsx`；不支持 `.xls`、CSV、加密工作簿，也会拒绝包含宏或数字签名的工作簿包。
- 源数据中的完整字段组合必须唯一，跨源工作表重复也会停止。
- 任一比较字段为空的行不参与匹配；比较字段中出现公式时会停止。需要比较公式结果时，请先在工作副本中将相关字段转为固定值。
- 源列与目标列数量必须一致；显式配置的比较规则数量也须一致。缺列或重复列会停止。
- 标黄操作修改指定单元格的填充样式，不改变其业务值。需要标黄的空白单元格若尚不存在，会补建仅含样式的空单元格。
- 生成前后会检查输入文件哈希，并校验输出中的数据及样式；已有输出文件不会被直接覆盖。如果所有匹配单元格原本已是黄色，写入模式会提示无需输出。
- 写入针对常规 OOXML 结构。特殊来源或非标准结构的文件如无法处理，可先用 Excel/WPS 另存为普通 `.xlsx` 后重试。

## 仓库文件管理

仓库提供通用示例配置，实际业务文件留在本地。配套 `.gitignore` 忽略 Excel 文件、`match_config.json`、原项目本地说明及 Python 缓存；网页手动上传时也请自行选择脚本、README、示例配置与忽略文件。

脚本内置默认值与示例配置均使用虚构信息。本地旧配置可保存为 `match_config.local.json`，该文件不会被自动加载，且已列入忽略规则；需要使用时显式传入 `--config .\match_config.local.json`。自行填写的文件名、工作表名及未匹配数据会按实际配置显示，公开运行截图或日志时请使用示例数据。
